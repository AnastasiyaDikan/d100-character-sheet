# Как отправить проект на GitHub

Эта инструкция сохраняет исходный код проекта в GitHub. Папки `node_modules` и `dist` загружать не нужно: они уже исключены через `.gitignore` и создаются заново командами установки и сборки.

## 1. Подготовка

1. Зарегистрируйтесь или войдите на [GitHub](https://github.com/).
2. Установите [Git](https://git-scm.com/download/win), если он ещё не установлен.
3. Распакуйте архив проекта и откройте папку `d100-character-sheet` в VS Code через **File → Open Folder**.
4. Откройте **Terminal → New Terminal**.

## 2. Создание пустого репозитория

1. На GitHub нажмите **New repository**.
2. Введите имя, например `d100-character-sheet`.
3. Выберите **Public**, если проект и его код должны быть доступны всем по ссылке.
4. Не добавляйте README, `.gitignore` или лицензию: эти файлы уже есть в проекте.
5. Нажмите **Create repository** и оставьте открытой страницу с адресом репозитория.

## 3. Первая отправка из VS Code

В терминале VS Code по очереди выполните:

```powershell
git init
git add .
git commit -m "Первая рабочая версия чарника"
git branch -M main
git remote add origin https://github.com/ВАШЕ-ИМЯ/d100-character-sheet.git
git push -u origin main
```

В предпоследней команде замените `ВАШЕ-ИМЯ` и адрес репозитория на данные со страницы GitHub. При первой отправке GitHub может открыть окно браузера для входа — подтвердите авторизацию.

Если Git попросит представиться, один раз выполните:

```powershell
git config --global user.name "Ваше имя"
git config --global user.email "ваша-почта@example.com"
```

После этого снова выполните команды `git commit` и `git push`.

## 4. Как отправлять следующие изменения

После правок и успешной локальной проверки:

```powershell
npm run typecheck
npm test
git add .
git commit -m "Краткое описание изменений"
git push
```

После `git push` обновлённые файлы появятся в том же репозитории.

## Важно о рабочей ссылке

GitHub хранит код, но сам по себе не запускает это приложение. Текущая сборка использует серверную часть Vinext/Cloudflare, поэтому обычный переключатель **GitHub Pages** для неё не подходит. Для публичной рабочей ссылки репозиторий лучше подключить к Cloudflare Workers или развернуть через встроенный хостинг проекта. Это отдельный шаг: сначала загрузите и проверьте репозиторий, затем можно будет настроить публикацию без изменения данных персонажей.
