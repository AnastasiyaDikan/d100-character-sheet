# Как подключить сообщения об ошибках и предложениях к Discord

Форма в чарнике отправляет сообщения в выбранный канал Discord через вебхук. Адрес вебхука хранится как секрет Cloudflare: посетители сайта не видят его в коде или браузере.

## 1. Создать вебхук в Discord

1. Откройте нужный сервер и выберите закрытый канал для сообщений.
2. Нажмите **Изменить канал → Интеграции → Вебхуки → Новый вебхук**.
3. Назовите его, например **Обратная связь чарника**.
4. Нажмите **Копировать URL вебхука**. Не публикуйте эту ссылку и никому её не пересылайте.

## 2. Сохранить вебхук в Cloudflare

1. Откройте Cloudflare Dashboard → **Workers & Pages** → проект чарника.
2. Перейдите в **Settings → Variables and Secrets**.
3. Нажмите **Add variable**.
4. Выберите окружение **Production**. Для тестовых развёртываний можно также выбрать **Previews**.
5. В поле **Key** укажите строго:

   ```text
   FEEDBACK_DISCORD_WEBHOOK_URL
   ```

6. В поле **Value** вставьте полный URL вебхука Discord и оставьте включённым переключатель **Secret**.
7. Нажмите **Add variable and deploy**.

## 3. Опубликовать актуальную версию

После локальной проверки отправьте изменения в GitHub:

```powershell
npm install
npm run typecheck
npm run build:local
git add .
git commit -m "Версия 0.20.0: выбор оружия в боевых действиях"
git push
```

Cloudflare автоматически соберёт новую версию из ветки `main`. Дождитесь успешного развёртывания и обновите сайт через `Ctrl+F5`.

## 4. Проверить отправку

1. На опубликованном сайте откройте **«Сообщить о проблеме/предложении»**.
2. Заполните имя, тип и описание длиной не менее 10 символов.
3. Нажмите **«Отправить»**.
4. Зелёная надпись **«Сообщение доставлено в Discord»** появляется только после успешного ответа Discord.
5. В выбранном канале должна появиться карточка с именем, типом, описанием, версией чарника и адресом страницы.

## Если сообщение не приходит

- убедитесь, что имя секрета написано без пробелов: `FEEDBACK_DISCORD_WEBHOOK_URL`;
- проверьте, что секрет добавлен именно для **Production**;
- после добавления секрета обязательно дождитесь нового развёртывания;
- проверьте, что вебхук Discord не был удалён и относится к нужному каналу;
- обновите опубликованный сайт через `Ctrl+F5`;
- если форма пишет, что Discord отклонил канал, создайте новый вебхук и замените значение секрета в Cloudflare.

Сам URL вебхука нельзя добавлять в GitHub, `.env`, скриншоты или сообщения: достаточно хранить его только в секретах Cloudflare.
